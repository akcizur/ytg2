# Free 3D model assets

Bundled Kenney CC0 assets used as the game's basic 3D model layer.

| Model | Source pack | License |
|---|---|---|
| building-a | Kenney City Kit (Commercial) | CC0 1.0 |
| building-skyscraper-a | Kenney City Kit (Commercial) | CC0 1.0 |
| light-curved | Kenney City Kit (Roads) | CC0 1.0 |
| sedan | Kenney Car Kit | CC0 1.0 |
| police | Kenney Car Kit | CC0 1.0 |
| tree-default | Kenney Nature Kit | CC0 1.0 |

Source: https://kenney.nl

The models are stored as base64 text files in `public/assets/models/kenney/` so the game remains a static GitHub Pages build without a runtime CDN dependency.
